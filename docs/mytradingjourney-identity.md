# A life in progress: MyTradingJourney visual identity

MyTradingJourney now uses its own ivory, forest and brass visual language across the personal workspace, Learning Library, research landing pages, reader and account screens. The existing public landing page remains in the same editorial family.

## Section experiences

- Mindset & Vision: reflective split hero, summaries derived from saved intentions, a visual inspiration board, and original first-person quotes. Entry counts describe saved records; they do not imply goal completion.
- Trade Journal: preparation / execution / reflection framing, study imagery and retained record cards.
- Builder’s Desk: a distinct graphic experiment loop and summaries of existing stages.
- Document Vault: a collection introduction and attachment counts.
- Weekly Reviews: notice / question / choose prompts and original record management.
- Learning Library: an editorial reading room, a compact Files & backups disclosure, existing searchable catalog and reading controls.
- Backtesting: a practice-room introduction and shared branding outside replay. The retained reference skin is overridden on research landing pages. Chart canvas, drawing tools and engine behavior remain in their existing replay layout.
- Reader and account screens: matching typography, surfaces and colors while retaining independent paper appearance and authentication behavior.

Navigation is grouped around practice, learning and building. Phones use a collapsible workspace menu. Existing saved light/dark preferences continue to apply. New visual CTAs open the original entry form, with no new record schema, key, account, migration or backend change.

Only the previously approved images are reused. Counts are generated from saved record metadata. Static editorial content never interpolates user-provided HTML. Search results retain escaped user content and a clear empty result. Route changes return the page to the top.

## Verification

All 176 regression tests pass, alongside JavaScript syntax checks. Browser checks cover light and forest-dark Mindset layouts, section navigation, library search and backup control visibility, research styling, a 390px mobile iframe, and menu open/close behavior. An isolated memory-backed preview verifies that the new intention CTA opens the existing form, saves a new entry, updates summaries and shows empty search results. That fixture and its records are preview-only and are not published. A fixture-only UUID shim supports the preview's HTTP hostname; production remains HTTPS.
