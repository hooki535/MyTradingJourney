# Fitted reading-collection covers

The 24 built-in books now use original MyTradingJourney vector cover designs, rather than lifestyle photographs containing books. A matching generic cover is included for personal titles. Each design has a 360 × 540 viewBox, consistently wrapped title, author, category and restrained geometric artwork. These are collection thumbnails, not reproductions of official publisher jackets.

The homepage, preview dialogs, workspace reading cards, library introduction and catalog share these SVG assets. Homepage covers are larger, fitted with `object-fit: contain`, and never cropped. Narrow phones show a single card per row. Existing account-uploaded library covers still take precedence; no saved reading record or uploaded file is modified.

All 25 SVG files pass XML validation, all 176 regression tests pass, and JavaScript syntax checks pass. Browser verification covers all six featured covers, preview dialogs, matching portrait proportions, and the narrow phone layout.
